## 2. 缺口

1. **两次 Fresh 的启动没有录像**。两次都是 Xiang Mao 在网页上亲自点击 Start Research 发起的，运行中的处理页也没有录。本轮不补造启动录像。
2. **标注条没有进入视频帧**。本轮用软字幕轨和章节补标注，没有烧进画面：本机 ffmpeg 没有 drawtext / libass，而且烧进画面就要重编码。
3. **冻结视频是 Round 27 代码（b5e91198）录的**，不能用来证明两次 Fresh 所用代码（1b53b921）的页面行为。
4. **冻结视频的两个模拟场景**，画面上只有截断的 run_id（`t4-simul…1008`）和 completed / failed 状态，没有"模拟"字样。"模拟"标签只出现在字幕、章节和本索引里。
5. **没有一段视频在同一个 run 上同时覆盖全部步骤和注入失败**。Fresh 视频覆盖了 Research 到 Export 的全部步骤；注入失败、SNDK 无主冲突展示在冻结视频里。
