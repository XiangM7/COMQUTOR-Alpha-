# Repository Cleanup v0.1.2 — Pre-Deletion Inventory

Written before any deletion. Investigation method: repository-wide `grep`/`find` for imports, direct file references, docstring/prose mentions, package entry points (`pyproject.toml`), CI/Docker references, and provenance-string mentions inside `docs/audit_artifacts/` (JSON/MD). That result shaped a conservative final policy: only delete items with **zero** references of any kind, anywhere.
