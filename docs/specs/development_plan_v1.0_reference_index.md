## Explicit Non-Implied Items

Development Plan §5.1 requires natural language to become a standard claim schema and defines safe failure. It does **not** state that all segmentation must be performed by an LLM, nor does it prohibit deterministic candidate segmentation.

The following are not Development Plan v1.0 requirements and must not be labeled `SOURCE_FROZEN`: Evidence Stance five-way classification, ticker-specific five-way classification, Clause Graph, Counter-Alpha stance, and dynamic invalidation extraction. Evidence Stance currently has `JOHN_LATER_REQUIREMENT` provenance; the others remain later requirements, proposed extensions, or unknown until separately evidenced and approved.
